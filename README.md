# Аудио-резак

Страница для вырезания фрагмента из mp3: загрузил файл → увидел волну → выделил кусок → скачал.
Всё работает прямо в браузере, файл никуда не отправляется.

**Открыть:** <https://makhnanov.github.io/audio-cutter/>

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | оформление (тёмная тема) |
| `app.js` | вся логика: декодирование, волна, выделение, экспорт |
| `worker.js` | кодирование mp3 в отдельном потоке |
| `vendor/lame.min.js` | энкодер mp3 (lamejs 1.2.1), лежит локально — интернет не нужен |

## Как запустить

Положить папку в корень сайта и открыть `index.html`. Для локальной проверки:

    cd /var/www/audio-editor
    make              # поднимает http://127.0.0.1:8777/, Ctrl+C — остановить
    make open         # то же самое, но сразу открывает страницу в браузере
    make PORT=9000    # на другом порту
    make stop         # прибить сервер, забытый в фоне

Страница работает и при открытии файла напрямую (`file://`), но тогда браузер не даёт
запустить Worker, и кодирование mp3 идёт в главном потоке — медленнее. Код это
отслеживает и переключается сам.

## Что умеет

- Загрузка перетаскиванием или через выбор файла. Открывает всё, что умеет браузер:
  mp3, wav, ogg, m4a, flac.
- Волна с линейкой времени, обзорной полосой внизу и масштабированием до 4 мс
  (`Ctrl`+колесо — масштаб, колесо — прокрутка).
- Выделение мышью, подстройка краёв, перенос выделения за полоску сверху,
  ручной ввод времени в формате `1:23.456`.
- Прослушивание выделения, в том числе по кругу.
- Экспорт в MP3 (128–320 кбит/с) или WAV 16 бит, с плавными краями по 20 мс,
  чтобы на стыках не щёлкало.

## Про скорость

Кодирование mp3 идёт примерно в 8 раз быстрее реального времени: минутный фрагмент —
около 8 секунд. Энкодер прогревается в фоне сразу после загрузки файла, иначе первый
экспорт был бы заметно дольше из-за прогрева JIT.

Если у исходника частота дискретизации, которую не понимает LAME, фрагмент
автоматически пересчитывается в 44100 Гц.
